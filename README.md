# AMGDiAG — Premium Automotive Technology Website

Премиальный многостраничный сайт для бренда AMGDiAG — диагностика, кодирование и активация функций Mercedes-Benz.

## Структура

- `index.html` — главная страница (Hero, Услуги, Technology, Автомобили, О компании, Контакты)
- `css/styles.css` — основные стили (тёмная премиальная палитра, адаптив)
- `js/script.js` — анимации появления, sticky header, форма заявки
- `services/` — отдельные страницы услуг
- `images/` — фотографии (свободные stock-изображения Mercedes)

## Как запустить

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
cd amgdiag
python3 -m http.server 8080
```

Затем перейдите на http://localhost:8080

## Особенности

- Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- Sticky header с эффектом появления фона при скролле
- Плавные анимации появления секций (Intersection Observer)
- Форма заявки с переходом в WhatsApp
- Рабочие ссылки на WhatsApp, Telegram, телефон, Яндекс.Карты
- SEO-метатеги
- Минималистичный премиальный стиль в духе Mercedes-AMG
